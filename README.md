#מטלה 2- תכנות מערכות 2

##במטלה זו התבקשנו ליצור מחלקה של מטריצה ריבועית המכילה מספרים ממשיים ולממש אופרטורים שונים. 
במטלה מימשתי:
מחלקה של מטריצה ריבועית (SquareMat) שיש בה בנאי (constructor), בנאי מעתיק (copy constructor) ומפרק (destrcutor) ואת כל האופרטורים שבישקו לממש במטלה.
קובץ הצהרות (header) שיש בו יש את החתימות של האופרטרוים ומימוש של פונקציות בסיסיות כמו ה-getters ו-setters.
קובץ main המדגים את השימוש באופרטורים. 
קובץ טסטים (SquareMatTest) שמתשמש ב-'doctest.h' כדי להכין את הטסטים. כתבתי טסטים לבנאי, בנאי מעתיק ולכל אופרטורים שממשתי. 
בסוף הכנתי Makefile שמקמפל את כל הקבצים בעשרת הפקודות הבאות:
1. הפקודה make main - מריץ את הmain
2. הפקודה make test - מריף את הטסטים
3. הפקודה make valgrind -שבודק זליגות זכרון
4. הפקודה make clean - מוחק את הקבצים הלא רלווטנים אחרי ההרצה
